# Portfolio
My professional portfolio.


A professional software engineering portfolio showcasing my technical expertise, professional experience, engineering projects, and areas of interest.

The application is developed using Angular and TypeScript and deployed through GitHub Pages.

## Project Overview

This project aims to establish a professional online presence and provide a centralized platform to showcase:

* Professional experience and engineering background.

* Technical skills and technology expertise.

* Software development projects and implementations.

* System design and architecture experience.

* Educational qualifications.

* Professional contact information.

The project is developed following software engineering best practices, including modular architecture, version control, code quality, automated testing, and CI/CD.
